# โปรโตคอลการรักษาความปลอดภัยของรหัสผ่านและความลับ (Secrets Protocol)

[English](SECRETS_PROTOCOL.md) | ภาษาไทย

โปรเจกต์นี้ปฏิบัติตามโปรโตคอลรักษาความลับที่เข้มงวดสำหรับการดูแลข้อมูลสิทธิ์และรหัสผ่านทั้งหมด

---

## กฎหลัก (Main Rule)

ผู้ใช้งานเป็นเจ้าของคีย์และความลับทั้งหมด

นักพัฒนาและ AI Agent มีหน้าที่อธิบายวิธีขอคีย์ สถานที่จัดเก็บ และการตรวจเช็กการเชื่อมต่ออย่างปลอดภัยเท่านั้น

---

## สิ่งที่อนุญาตให้ทำได้ (Allowed Actions)

- สร้างไฟล์ตัวอย่างแม่แบบ `.env.example`
- อธิบายขั้นตอนการสร้างและเติมค่าใน `.env.local`
- อธิบายวิธีขอ Supabase URL, Anon Key และ Service Role Key
- อธิบายการตั้งค่า Google OAuth
- อธิบายการตั้งค่า Environment Variables บน Vercel
- ตรวจสอบการคงอยู่ของตัวแปรสภาพแวดล้อม
- รันสคริปต์ตรวจเช็กความถูกต้องแบบปลอดภัย (`pnpm check-env`)
- รายงานสถานะเพียง `OK`, `Missing` หรือ `Invalid`

---

## ข้อห้ามเด็ดขาด (Forbidden Actions)

- ห้ามพิมพ์ คัดลอก หรือแสดงรหัสความลับลงใน Log หรือ Console
- ห้ามพิมพ์เนื้อหาภายในไฟล์ `.env.local` ออกมาแสดงผล
- ห้าม commit ไฟล์ `.env.local` ลงใน Git Repository
- ห้ามใส่ `SUPABASE_SERVICE_ROLE_KEY` ในโค้ดฝั่ง Frontend (`apps/web`)
- ห้ามใส่ Google Client Secret ในโค้ดเบราว์เซอร์
- ห้ามบันทึก JWTs หรือ Access Tokens ลงใน Log
