# นโยบายความปลอดภัยและการเคารพสิทธิ์ (Security & Policy Specification)

[English](SECURITY_AND_POLICY.md) | ภาษาไทย

## วัตถุประสงค์ (Purpose)

โปรเจกต์นี้ได้รับการออกแบบมาเพื่อให้ตระหนักถึงสิทธิ์ในเนื้อหาและปลอดภัยต่อการใช้งาน

ระบบจะต้องไม่กลายเป็นเครื่องมือดาวน์โหลดที่ไม่จำกัดขอบเขตหรือไม่สนใจสิทธิ์ในเนื้อหา

---

## กฎเหล็กความปลอดภัย (Core Rules)

1. ตรวจสอบความถูกต้องของ URL ก่อนเริ่มการเชื่อมต่อเครือข่ายเสมอ
2. รันการตรวจสอบนโยบายสิทธิ์ (Policy Check) ก่อนวิเคราะห์สื่อเสมอ
3. แสดงผลลัพธ์การวิเคราะห์ แล้วต้องมีการยืนยันสิทธิ์จากผู้ใช้งานก่อนนำเข้าคิวงานเสมอ
4. บล็อกและปฏิเสธ URL ที่ไม่ปลอดภัยหรือไม่ได้รับอนุญาต
5. บันทึกประวัติการตัดสินใจนโยบายสิทธิ์ลงใน `policy_logs`
6. เก็บความลับและ Keys ทั้งหมดไว้ฝั่ง Server-Side เท่านั้น
7. กำหนดสิทธิ์ระดับตารางด้วย Supabase RLS
8. จัดเก็บไฟล์ผลลัพธ์เฉพาะเจ้าของบัญชี และล้างไฟล์ชั่วคราวตามระยะเวลาที่กำหนด (Default Temporary Output)

---

## ประเภท URL ที่ถูกบล็อก (Blocked URL Types)

ระบบจะบล็อกและปฏิเสธ URL ต่อไปนี้เสมอ:

- `file://`
- `ftp://`
- `localhost`
- `127.0.0.1`
- `0.0.0.0`
- ช่วง IP ส่วนตัวภายใน (Private IP Ranges: 10.x.x.x, 192.168.x.x, 172.16-31.x.x)
- ช่วง Link-local IP (169.254.x.x)
- ชื่อ Hostname ภายในระบบ
- การ Redirect ที่สงสัยว่าจะเข้าถึงเครือข่ายภายใน (SSRF Attack)

---

## ระบบป้องกัน SSRF (Server-Side Request Forgery Protection)

ก่อนทำคำขอเชื่อมต่อภายนอก (Outbound Requests) ระบบจะต้อง:

- แยกแยะโครงสร้าง URL อย่างรัดกุม
- แปลง Hostname เป็น IP Address
- ปฏิเสธ IP ภายในและช่วง IP ส่วนตัว
- บังคับใช้เฉพาะโปรโตคอลที่ได้รับอนุญาต (`http`, `https`)
- จำกัดจำนวนครั้งในการ Redirect และตรวจสอบเป้าหมายของการ Redirect ซ้ำ
- กำหนดเวลาหมดอายุในการเชื่อมต่อ (Timeout)
- จำกัดขนาดข้อมูลตอบกลับสูงสุด

---

## นโยบายไม่ข้ามระบบป้องกัน (Non-Bypass Policy)

ระบบจะต้องไม่ข้ามระบบป้องกันของแพลตฟอร์มใดๆ:
- ห้ามข้าม DRM (Digital Rights Management)
- ห้ามข้ามหน้าต่างล็อกอิน หรือการสมัครสมาชิก (Paywall / Login Walls)
- ห้ามใช้ Cookies ของเบราว์เซอร์เพื่อเข้าถึงเนื้อหาที่ถูกจำกัดสิทธิ์
- ห้ามข้ามการยืนยันอายุ (Age Gate) หรือการจำกัดพื้นที่ภูมิภาค (Geo-restriction)
