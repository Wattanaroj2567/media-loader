# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately through [GitHub's private
vulnerability reporting for this repository](https://github.com/Wattanaroj2567/media-loader/security/advisories/new).
Do not disclose an unpatched vulnerability in a public issue or discussion.

Include the affected component, steps to reproduce, and the impact you observed.
Do not include real user data, credentials, or other secrets in a report.

## Supported Versions

This project does not publish versioned security support windows. Please report
issues against the latest code on the `master` branch.

Reports are reviewed as maintainer availability allows. No response or fix
timeline is guaranteed.
